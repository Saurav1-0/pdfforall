Privacy Policy

Zero cloud uploads. Zero data retention.

1. Zero File Uploads

Every single file you drop into PDFforAll is processed strictly within your device's memory using client-side JavaScript (pdf-lib, pdf.js, and jsPDF). No file bytes are transmitted over the Internet.

2. No Logs or Passwords Stored

When you encrypt or unlock password-protected documents, encryption key generation and verification take place directly in your local browser sandbox.
