PDFforAll launch-readiness update
================================

Analytics setup
---------------
File: js/consent-analytics.js
1. Replace GA4_ID = "" with the real GA4 Measurement ID, e.g. G-XXXXXXXXXX.
2. Replace CLARITY_ID = "" with the Microsoft Clarity project ID.
3. Do not paste secret API keys here. These are public site/project identifiers, not secrets.
4. GA4 and Clarity load only after a visitor clicks "Accept analytics". Rejected visitors do not load either script.
5. The existing Vercel Web Analytics snippet was retained where it already existed.

SEO
---
Every existing public HTML page now has a unique title, description, canonical URL, Open Graph and Twitter preview metadata.
Submit https://www.pdfforall.in/sitemap.xml in Google Search Console and Bing Webmaster Tools.
The sitemap contains the 34 existing public content pages. The custom 404 page is excluded.
Search ranking is not guaranteed by metadata alone; content quality, backlinks, technical performance and indexing also matter.

Hosting
-------
vercel.json adds a redirect from the apex host pdfforall.in to https://www.pdfforall.in and security headers including HSTS.
Vercel automatically provisions HTTPS for correctly configured domains. Verify both domain variants in Vercel > Project > Settings > Domains after deployment.

Contact form limitation
-----------------------
The contact form now has browser email/required-field validation, input length limits and a honeypot field.
It is NOT connected to an email delivery service or server endpoint. It explicitly tells visitors that messages are not sent.
To make it functional, connect a server-side form provider/function and verify CAPTCHA/Turnstile server-side. Never put an email provider API key in browser JavaScript.

Performance
-----------
The large 2048px logo was resized to 512px and optimized. The favicon was already present.
A live PageSpeed/Lighthouse measurement was not possible from the source archive. After deployment, test the homepage and representative tool pages at https://pagespeed.web.dev/ and review mobile Core Web Vitals.
